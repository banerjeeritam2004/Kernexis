# Kernexis

## A C++ Linux-Based System Diagnostics and Resource Monitoring Framework

## 1. Project Introduction

Kernexis is a C++-based Linux system diagnostics and resource monitoring framework. It is designed to collect, process, and display important system information through a command-line interface.

The system will monitor CPU, memory, processes, storage, and other operating-system-level resources. It will use Linux system interfaces and system programming concepts to obtain and analyze system information.

The project demonstrates practical concepts of Linux, C++, system programming, computer architecture, operating systems, process management, file handling, and multithreading.

---

## 2. Problem Statement

Linux provides different commands, files, and system interfaces for obtaining information about system resources and running processes. Users often need to use multiple commands to understand the current state of their system.

Kernexis aims to provide a single command-line application that organizes important system information and provides basic diagnostics in an easy-to-understand format.

---

## 3. Objectives

The main objectives of Kernexis are:

1. To develop a Linux-based system monitoring application using C++.
2. To collect CPU and memory information.
3. To monitor running processes.
4. To monitor storage usage.
5. To use Linux system interfaces such as the /proc filesystem.
6. To demonstrate system programming concepts.
7. To implement basic system diagnostic logic.
8. To use multithreading for background monitoring.
9. To maintain system activity and diagnostic logs.
10. To apply Git and GitHub for version control and project management.

---
